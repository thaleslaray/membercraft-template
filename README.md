# Área de membros (modelo)

Sistema de área de membros para escolas online, em português do Brasil: TanStack Start + Cloudflare Workers + D1 + R2 + Filas. O código está em `app/`.

Leia `app/README.md`: ele diz o que você precisa ter (conta Cloudflare, provedor de e-mail, Vimeo, gateway de pagamento opcional), o que o sistema não faz, como rodar no seu computador e como publicar.
